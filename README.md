# IntellMeet – AI-Powered Enterprise Meeting & Collaboration Platform

IntellMeet is an AI-powered enterprise meeting and collaboration platform built with the MERN stack. The platform is designed to provide real-time meetings, collaboration, AI-powered meeting intelligence, chat, task management, and team workspaces.

---

## 🚀 Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.io

### Security & Middleware
- JWT Authentication
- CORS
- Helmet
- dotenv
